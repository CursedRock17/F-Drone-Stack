# Visualization

### Prerequisites
  - Download [Foxglove](https://foxglove.dev/download)
  - Install Foxglove -> ROS 2 Bridge `sudo apt install ros-humble-foxglove-bridge` 
  - micro_ros_f_drone & dRehmFlight prepared

1) Turn on the drone and run the uROS node for "Odometry"

2) Turn on Foxglove visualization
    `ros2 launch foxglove_bridge foxglove_bridge_launch.xml`
