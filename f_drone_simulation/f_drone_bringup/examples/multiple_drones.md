# Multiple Drones
-------------------------
This tutorial showcases our ability to have mutliple agents (drones) interact with the 
use of a human

### Running the World
1) Open an instance of the terminal (in the hardware directory)
2) Source your local ROS environment : `source /opt/ros/humble/setup.bash`
3) Build the simulation package `colcon build && source install/setup.bash`
4) Run the launch file `ros2 launch f_drone_simulation multi_drones_autonomy.launch.py`
5) Enjoy!
